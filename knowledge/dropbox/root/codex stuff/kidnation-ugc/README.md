# KidNation UGC Pack

This pack is designed to help you generate a lot of realistic UGC-style videos quickly for KidNation.

What is included:
- `platform-recommendation.md`: current free/free-tier platform recommendation
- `ugc-scripts.csv`: batch scripts with hooks, creator angles, CTAs, and video prompts
- `review-checklist.md`: fast pass/fail checklist for exports

Important assumptions:
- KidNation is a kid/family-facing brand
- We should avoid fake child testimonials and instead use adult creator perspectives like parents, caregivers, teachers, or activity planners
- Product specifics were not provided yet, so scripts use placeholders like `[PRODUCT]`, `[BENEFIT]`, and `[CTA_URL]`

Best first move:
1. Open `platform-recommendation.md`
2. Pick 5 to 10 scripts from `ugc-scripts.csv`
3. Replace placeholders with real KidNation details
4. Generate a first batch
5. Review against `review-checklist.md`

If you send me KidNation's product page, offer, target age range, and brand voice, I can turn this into a fully brand-specific batch next.
