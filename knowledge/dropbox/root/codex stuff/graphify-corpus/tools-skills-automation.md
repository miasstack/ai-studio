# Tools, Skills, And Automation

## Canonical Inputs

- `prepare-kling-reference-pack/` is the reusable workflow for downloading inspiration clips, extracting first frames, and organizing Kling source packs.
- `generate-a-video/` contains the video generation automation pipeline, provider logic, run state handling, and prompt data.
- `scripts/flow_nano_batch.js` and `scripts/run_flow_ship_storyboard.sh` support Flow storyboard generation.
- `plugins/textbelt-sms/` contains the Textbelt SMS local plugin.
- `seedance-prompts-skill/` and `skills/flow-scene-identity-anchoring/` are local prompt/workflow skills.
