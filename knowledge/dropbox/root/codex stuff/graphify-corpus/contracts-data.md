# Contracts, Music Docs, And Property Data

## Canonical Inputs

- Top-level `.docx` files are music agreement drafts and amended/fixed variants.
- `contract-redraft/` contains the Third Street artist agreement source and redraft material.
- `south_florida_code_violation_properties_2026-04-26.csv`, `south_florida_code_violation_properties_enriched_2026-04-26.xlsx`, and `zillow_enrichment_2026-04-26.json` are the property/code-violation data set.
- `graphify-out/converted/` contains temporary Markdown conversions of office files created by Graphify detection.

## Query Ideas

- What changed between the original, amended, fixed, and template-format agreement files?
- Which property data fields connect code violations to enrichment data?
- Which contract files share the same parties, clauses, or formatting assumptions?
