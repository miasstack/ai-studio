# Artist Fan DNA Intelligence — System Prompt
### Drop an Instagram and/or Spotify link. The AI does the rest.

---

## HOW TO USE

1. Open Claude (or any AI with web search)
2. Paste the SYSTEM PROMPT below
3. Then just type something like:
   - `@juhn`
   - `https://open.spotify.com/artist/...`
   - `@artistname on Instagram, also on Spotify as "Artist Name"`
4. The AI will research the artist and generate the full report
