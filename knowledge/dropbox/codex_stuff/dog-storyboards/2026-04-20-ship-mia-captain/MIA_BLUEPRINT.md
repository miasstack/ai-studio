## Mia Blueprint Rule

For every new video scenario, remake Mia's character sheet first in the scenario-specific outfit before generating storyboard images or videos.

Reason:

- this locks identity first
- it improves outfit consistency
- it gives Flow a stronger ingredient for every later image and video
- it reduces drift between clips

## Workflow Standard

1. Define the scenario role and outfit.
2. Generate a new Mia character sheet in that exact outfit.
3. Use that updated sheet as the main identity ingredient for all storyboard images.
4. Use the same updated sheet again for all video clips in that scenario.

## Future Rule

Do not reuse the old default Mia sheet when the outfit changes in a meaningful way.

Examples:

- farmer video: make a farmer-sheet version of Mia first
- captain video: make a naval-captain-sheet version of Mia first
- firefighter video: make a firefighter-sheet version of Mia first
- train conductor video: make a conductor-sheet version of Mia first

Identity stays the same. The outfit-specific character sheet changes per scenario.
